# AURELION — концепт сайта

- `index.html` — главная страница марки, история, конфигуратор и форма обращения.
- `vespera.html` — страница модели с галереей и полной таблицей характеристик.
- `public/aurelion-vespera-brochure.pdf` — трёхстраничная брошюра.
- `public/` — локальные изображения и знак марки.
- `.github/workflows/pages.yml` — автоматическая публикация статического сайта через GitHub Pages.
- `PUBLISH.md` — инструкция для публикации в новом публичном репозитории `aurelion-website`.

Для локального запуска из этой папки:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Сайт полностью статический. Конфигурация Vespera сохраняется в `localStorage`, а ссылка на неё кодируется в URL-параметре `build`. Форма демонстрационная и не отправляет данные на сервер. Адрес `concierge@aurelion.example`, телефон и домен `.example` — заполнители. История марки и характеристики автомобиля также придуманы для концепта.
